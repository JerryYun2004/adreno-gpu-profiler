The phone exposes /dev/dri/card0 and /dev/dri/renderD128, but both resolve to the Qualcomm display subsystem qcom,mdss_mdp using msm_drm / sde-kms. The actual Adreno GPU is exposed through KGSL at /dev/kgsl-3d0 and /sys/class/kgsl/kgsl-3d0. KGSL reports the GPU model as Adreno830v2 and exposes busy, clock, frequency, clock-statistics, fault, and perfcounter nodes. Therefore, Mesa PPS should still be tested, but if it cannot access gpu.counters.msm, the likely reason is that this Android kernel exposes the Adreno GPU through KGSL rather than a Freedreno-compatible GPU DRM render node.
